The decision rule is: if the path varies by input, use an agent; otherwise a workflow. Seven of the ten requests do not need a loop — scale-only and single-allergen are always search → scale → at most one profile. On those the workflow matches the agent at 7/7, with 0 tokens and <1 ms versus 42 s p50 and 76 921 tokens. Three requests are allergen-cascade: the substitute itself carries another allergen, so the next tool call depends on what get_allergen_profile returned. The workflow makes one profile call and scores 0/3. The agent scores 2/3 (W07 vegan-and-nut-free paneer; W09 vegan shakshuka). W08 (vegan gluten-free chicken curry, soy introducing wheat) beat both. That cascade class is the only one of the ten that forces an agent. It does not win the race: the workflow is ahead on latency, tokens, and cost per request.
